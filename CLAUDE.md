## Stack

- **Next.js 16.3.4** (App Router) with **React 19** and **TypeScript**
- **Tailwind CSS v4** — configured via `postcss.config.mjs`; uses `@import "tailwindcss"` and `@theme inline` in `globals.css` (v4 syntax, not `tailwind.config.js`)
- **Geist** font family via `next/font/google`
- **Capacitor** — wraps static export (`out/`) in native iOS shell; config in `capacitor.config.ts`, native project in `ios/`

## Next.js 16 breaking changes to know

This is **not** Next.js 14/15. Key API differences:

**`params` and `searchParams` are Promises** — always `await` them:
```tsx
// page
export default async function Page(props: PageProps<'/blog/[slug]'>) {
  const { slug } = await props.params
}

// layout
export default async function Layout(props: LayoutProps<'/dashboard'>) {
  const { team } = await props.params
}
```

**`PageProps` and `LayoutProps` are globally available** (no import needed) — generated by `next dev`/`next build`/`next typegen`. Pass a route literal for strict typing.

## Project structure

```
app/
  layout.tsx   # root layout — sets html/body, fonts, metadata
  page.tsx     # route: /
  globals.css  # Tailwind v4 entry + CSS custom properties
public/        # static assets served at /
next.config.ts # empty config (no customizations yet)
```

All new routes go under `app/` following App Router file conventions (`page.tsx`, `layout.tsx`, `loading.tsx`, `error.tsx`). Read `node_modules/next/dist/docs/` for this version's exact API before adding new Next.js features.
