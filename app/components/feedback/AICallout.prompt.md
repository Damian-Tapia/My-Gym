Amber-soft panel with a sparkles glyph — the only place the AI assistant speaks. Always dismissible, never blocking.

```jsx
<AICallout action="Aplicar a la rutina" onDismiss={hide}>
  Llevas 3 semanas con el mismo peso en press de banca. Puedes subir a 42.5 kg.
</AICallout>
```

Copy is plain and optional: state the observation, then the suggestion. Never more than one per screen.
